# LUMe Fitness Club — Nuovo sito

Prototipo e documentazione per la ricostruzione di **lumefitness.it** in stack moderno
(Astro + Tailwind, deploy Netlify). Vedi `ARCHITETTURA.md` per stack, struttura e roadmap.

## Contenuto
- `index.html` — mockup homepage (dark cinematic, colori brand, hero video, mobile-first)
- `mockup-assets/` — foto e video del brand ottimizzati per il web
- `ARCHITETTURA.md` — documento di architettura del progetto

## Anteprima locale
Apri `index.html` nel browser, oppure servi la cartella:

    python3 -m http.server 8000

Stato: **prototipo / brainstorm** — non ancora il sito Astro di produzione.
